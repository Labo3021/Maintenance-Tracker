# Maintenance-Tracker (gemma-diy-maintenance)

DIY maintenance assistant powered by Gemma 4.

## Structure

```
├── .gitignore   # Ignores .env, node_modules, etc.
├── README.md    # Quick setup instructions & demo script
├── frontend/    # (Person 1) UI, React/Next components, styles
├── backend/     # (Person 2) FastAPI/Express server, Gemma 4 pipeline
└── data/        # (Person 3) Mock DB JSON, test images, manual PDFs
```

## Quick setup

1. Clone the repo: `git clone <repo-url> && cd Maintenance-Tracker`
2. Copy env vars: `cp .env.example .env` and fill in keys
3. Backend: see [backend/README.md](backend/README.md)
4. Frontend: see [frontend/README.md](frontend/README.md)
